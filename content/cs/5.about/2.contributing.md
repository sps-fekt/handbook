Stránky příručky jsou soubory Markdown v repozitáři [sps-fekt/handbook](https://github.com/sps-fekt/handbook), ve složce `content/`. Web je čte přímo z GitHubu, takže změna ve větvi `main` se na webu objeví během chvíle, bez nového sestavení.

## Úpravy v prohlížeči

1. Na stránce, kterou chceš upravit, klikni na **Upravit na GitHubu** (pod seznamem „Na této stránce“).
2. GitHub otevře soubor v editoru. Přihlas se svým účtem. Pokud nemáš do repozitáře právo zápisu, GitHub si sám vytvoří kopii (fork) a změnu nabídne jako pull request.
3. Uprav text a klikni na **Commit changes**. Pokud nespravuješ web, vyber **Create a new branch** a otevři pull request, ať změnu někdo zkontroluje.

## Náhled změny

Změnu, která ještě není v `main`, si můžeš prohlédnout přímo na webu:

- pull request: `/pr/<číslo>/cs/...`, např. `/pr/12/cs/getting-started/welcome`
- větev: `/tree/<větev>/cs/...`
- konkrétní commit: `/blob/<hash>/cs/...`

## Úpravy přes Git

```bash
git clone https://github.com/sps-fekt/handbook.git
cd handbook
npm install
npm run dev
```

Web pak běží na [localhost:3000](http://localhost:3000) a čte stránky ze složky `content/` na disku. Změny pošli jako commit do nové větve a otevři pull request.

## Překlad

- Čeština je zdroj. Každá změna začíná v `content/cs/`.
- Anglická verze má **stejný název souboru** v `content/en/`.
- Které stránky je potřeba přeložit nebo aktualizovat, ukazuje [Stav překladu](/cs/translations). U zastaralé stránky tam najdeš, co se v češtině změnilo, a odkaz na úpravu anglické verze.

::tip
Opravuješ jen překlep a překlad se tím nemění? Napiš do popisu změny `lunaria-ignore` a stránka se ve stavu překladu neoznačí jako zastaralá.
::
