The handbook's pages are Markdown files in the [sps-fekt/handbook](https://github.com/sps-fekt/handbook) repository, in the `content/` folder. The site reads them straight from GitHub, so a change on the `main` branch shows up on the site shortly, without a new build.

## Editing in the browser

1. On the page you want to change, click **Edit on GitHub** (below the "On this page" list).
2. GitHub opens the file in its editor. Sign in with your account. If you don't have write access to the repository, GitHub makes a copy (fork) for you and offers the change as a pull request.
3. Edit the text and click **Commit changes**. Unless you maintain the site, choose **Create a new branch** and open a pull request so someone can review the change.

## Previewing a change

A change that isn't on `main` yet can be viewed on the site itself:

- pull request: `/pr/<number>/en/...`, e.g. `/pr/12/en/getting-started/welcome`
- branch: `/tree/<branch>/en/...`
- a specific commit: `/blob/<hash>/en/...`

## Editing with Git

```bash
git clone https://github.com/sps-fekt/handbook.git
cd handbook
npm install
npm run dev
```

The site then runs at [localhost:3000](http://localhost:3000) and reads the pages from the `content/` folder on disk. Commit your changes to a new branch and open a pull request.

## Translation

- Czech is the source. Every change starts in `content/cs/`.
- The English version has **the same file name** in `content/en/`.
- [Translation status](/en/translations) shows which pages need translating or updating. For an outdated page it links to what changed in Czech and to the English file's editor.

::tip
Only fixing a typo, so the translation doesn't change? Put `lunaria-ignore` in the commit message, and the page won't be marked as outdated.
::
